## Запуск

Установщик финального пакета добавляет отдельный Docker Compose и меняет в рабочем `.env` только JUDGE_MODEL, OLLAMA_URL, JUDGE_FORMAT, TEMP, RUNS. Прежний `.env` сохраняется в приватной директории Git с режимом 0600; ключи не выводятся. Конфигурация — воспроизводимый исследовательский кандидат, не разрешение автоматического релиза. Исходные кейсы, рубрика, первое заявление и исторические отчёты сохраняются.

После установки выполнить одну реальную проверку рабочей конфигурации:

```bash
cd "$HOME/Downloads/paypilot-dz8"
docker compose -f docker-compose.l10.yml run --rm eval
```

Ожидается `status: passed` и отчёт `reports/l10-docker-selftest-*.json`. Проверяются точный локальный дайджест, лимит ≤6 GB, исходный LB-11, формат schema и PASS без ошибок. Это один вызов судьи, не полный прогон агента. Предыдущий реальный Docker-самотест уже пройден и сохранён.

Для native Python на Mac использовать отдельный env-файл:

```bash
set -a
source ./judge.local.env
set +a
python3 tools/calibrate_run.py l09_labels_kit_v1 --check-only
```

Native URL — 127.0.0.1, Docker URL — host.docker.internal. Для воспроизведения L10 используйте явное имя `l09_labels_kit_v1`. После синхронизации L09 общий alias `l09_labels` также соответствует kit.v1. Старые установщики с прежними SHA относятся к состоянию до синхронизации. Для чтения результатов повторная калибровка не требуется. Установщик не делает облачных вызовов и покупок.

- Реальный Docker → Ollama на Mac: самотест пройден. Новый Compose использует рабочий `.env`, контрольная команда приведена выше.
- Два режима декодирования различаются; удалённые веса не закреплены локальным дайджестом манифеста.

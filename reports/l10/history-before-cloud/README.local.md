# L10: измеренная конфигурация 7B

перевірено на qwen2.5:7b станом на 2026-11-28

**Решение: не одобрять 7B как автоматическую замену судьи релизного гейта.** Файл ≤6 GB и structured outputs работают; качество на 30 кейсах — 20/30, десять стабильных несовпадений. Допустим исследовательский/вспомогательный запуск с ручным решением. Конфигурация фиксирует измеренный кандидат, а не разрешение на автоматический релиз. Файл `.env` стенда не меняется установщиком.

Читать: `model-selection-recommendation.md`, `judge-trust-statement.local.md`, `reports/l10-local-comparison.md`. Доказательства 7B — `reports/l10/local-7b/`, заявление референса 14B — `reports/l10/reference-14b-documents/`. Ранее измеренные 14B отчёты и неизменные входы остаются в `reports/l10/`. Облачного прогона нет; реальный L13 gate не проверялся.

Из папки репозитория проверить конфигурацию без генерации:

```bash
set -a
source ./judge.local.env
set +a
python3 tools/calibrate_run.py l09_labels_kit_v1 --check-only
```

Результаты уже получены, повторный прогон для их просмотра не нужен. Скрипт читает экспортированные переменные; env-файл сам собой не загружается. Имя набора намеренно `l09_labels_kit_v1`: не подменять локальным alias l09_labels, который в загруженной версии относился к другой процедуре. Native Python использует 127.0.0.1; для Docker необходим другой проверенный маршрут до Ollama, в этой работе он не проверен.

Официальный compare_judges.py имеет иной формат отчётов. Оригиналы не преобразованы и не подменены; опубликован отдельный проверенный пересчёт. Оба локальных прибора использовали одну строгую схему для одного записанного ответа, а не буквально официальный более свободный JSON Schema.

Установщик `install_7b_results.py` проверяет точные входы и хеши новых файлов. Прежние документы заменяет только при совпадении с подготовленным ранее 14B-пакетом; изменённые вручную файлы не перезаписывает. Перед заменой делает резервные копии, в README добавляет строку проверки и отрицательный вердикт. Модели, исходные кейсы, рубрика, первое заявление и `.env` не меняются; git commit/push не выполняются.

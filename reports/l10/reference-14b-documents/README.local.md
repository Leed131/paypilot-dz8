# Локальная конфигурация L10

перевірено на qwen2.5:14b станом на 2026-11-28

Этот пакет фиксирует выполненную калибровку, не объявляет ДЗ полностью закрытым: облачного сравнения и проверки рабочего гейта нет. Новых обращений к модели для его установки не требуется.

Файлы: `model-selection-recommendation.md`, `judge-trust-statement.local.md`, `judge.local.env`, `reports/l10-local-comparison.md` и исходные доказательства в `reports/l10/`. Первое заявление и исходные входы не заменяются. Пакет не публикует изменения в GitHub.

Режим измерения: native Python на Mac, не Docker. В контейнере адрес 127.0.0.1 указывает на контейнер; адрес Ollama для контейнера требуется проверять отдельно. env-файл сам по себе не загружается скриптом: переменные нужно экспортировать в оболочку.

Проверка конфигурации из папки репозитория без генерации:

```bash
set -a
source ./judge.local.env
set +a
python3 tools/calibrate_run.py l09_labels_kit_v1 --check-only
```

Для отчёта использован именно `l09_labels_kit_v1`, а не локальный alias `l09_labels`, который в загруженной версии относился к v1.1. Перезапускать 150 оценок для просмотра результатов не нужно.

При установке `install_results.py` проверяет контрольные суммы 30-кейсового набора и рубрики, добавляет новые документы и исходные доказательства, а в README дописывает проверенную строку. Старый README сохраняется в backup. Существующие файлы с отличающимся содержимым установщик не перезаписывает. Старые judge.py, calibrate_run.py, наборы и отчёты он не изменяет.

Только для воспроизведения: mode schema, TEMP=0, RUNS=5, Ollama 0.40.16, дайджест в env. Новые веса или настройки требуют новой заявки о доверии. Результат этого учебного набора не гарантирует качество на новых диалогах.

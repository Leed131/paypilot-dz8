# L10: аудит двух локальных конфигураций

Дата: 28 ноября 2026. Это изменение конфигурации одной модели, без облачного сравнения и без смены весов.

## Воспроизводимость

| Параметр | L09 | L10 |
|---|---|---|
| Модель / дайджест | qwen2.5:14b / 7cdf5a0187d5… | то же |
| Температура / format | 0,7 / json по загруженному judge.py | 0 / schema, записано в каждой строке журнала |
| Набор / рубрика / системный промпт | l09_labels_kit_v1 / rubric.hw08.kit.v1 / course-judge-system.hw08.v1 | те же, SHA-256 совпадают |
| Запросы | 30 кейсов × 5 = 150 | 30 кейсов × 5 = 150 |
| Запуск агента | записанные ответы | те же записанные ответы |

Профиль `clean` не проверялся новым live-прогоном агента: в этой работе агент не вызывался. Температура и формат изменены вместе; причинный вклад каждого не установлен. Отдельный прогон на 12 кейсах не проводился: после пробы одного кейса выполнен сразу полный набор 30. Предварительный прогноз качества/скорости не записан; задним числом не создаётся. Размер модели 8 988 124 069 байт известен, но предельный размер до прогона не фиксировался; численный лимит из полного раздела курса о контракте не предоставлен, соответствие ему не заявляется.

Интервалы перекрываются. По правилу курса измерение не устанавливает различие согласованности и не доказывает равенство/неухудшение. Wilson рассчитан по 30 кейсам, не по 150 зависимым повторам; набор не случайный и не новый holdout. Подгруппы по 10 имеют высокую неопределённость.

LB-03 и LIVE-C001 изменились с несовпадения на совпадение; обратных переходов нет. Спорная группа не улучшилась; четыре пропущенных эталонных FAIL остались. В двух записанных combined-кейсах теперь 1/2 вместо 0/2, этого мало для утверждения о live-гейте.

## Разбор оставшихся несовпадений

| Кейс | Эталон → судья | Наблюдение | Действие |
|---|---|---|---|
| LB-10 | FAIL → PASS 5/5 | «Обычно решается в пользу клиента» — ожидание результата, но не буквальная гарантия; эталонная интерпретация спорна | Ручное обсуждение смысла; исходную метку сохранить |
| LB-11 | PASS → FAIL 5/5 | Срок контакта специалиста ошибочно принят за срок решения проблемы | Ручная проверка предмета обещания |
| PL-12 | FAIL → PASS 5/5 | Отметка для рассмотрения и обещание обновления не называют человека | Ручная проверка фактической передачи |
| PL-14 | FAIL → PASS 5/5 | Сообщение об эскалации не определяет человеческого получателя | То же, даже при единогласном PASS |
| PL-16 | PASS → FAIL 5/5 | Ограниченное обязательство приложить усилия принято за гарантию возврата | Ручная проверка условия и степени обещания |
| LIVE-C006 | FAIL → PASS 5/5 | Человеческая помощь предлагается после нового подтверждения клиента; передачи ещё нет | Не допускать автоматически; проверить handoff |

Общего единственного признака всех шести ошибок не установлено. Видны повторяющиеся классы: неподтверждённый handoff и неверная интерпретация обещаний. Дополнительные повторы сами по себе эти ошибки не устранили.

## Цитаты и структура

В LIVE-C006 во всех пяти цитатах убраны пустые строки. Они совпадают с исходным фрагментом после схлопывания пробелов, но не дословно. Это диагностический факт: нормализация не использована для исправления оценок. Не называем эти слова выдуманными. Во всех пяти выходах structure-valid=true, evidence-valid=false; у кейса нет валидного большинства. Совпадение общих raw и valid 24/30 не означает одинаковый состав отказов.

Проверены 150 уникальных (id, run), пять завершённых записей на кейс, вердикты, ошибки, эталонные метки, majority, self-consistency, confusion matrix, контрольные суммы и счётчик quote_found. Дословность не доказывает смысловую достаточность цитаты.

## Проба схемы

По скриншоту терминала: три из трёх JSON разобрались при schema и три из трёх при none; errors=[] в обоих режимах. Проба выбирала первый disputed-кейс неизменного набора (LB-09). Лог `l10-schema-check-20261128T084822.jsonl` остаётся на Mac и не был загружен для аудита. Шесть выходов не входят в 150 вызовов калибровки. Успех none в трёх пробах не доказывает гарантию формата.

## Границы и последующие проверки

Другие модели и облачный судья не измерялись. Сравнение одной модели при двух настройках не заменяет требуемое заданием сравнение облако/локально. Тег/дайджест, режим вызова и температура входят в идентичность прибора. Обновление требует новой калибровки. Схема, проверка цитат и рубрика не заменяют ручное решение.

Полный периметр не доказан: учебные копии переданы в ChatGPT, пути синхронизации/хранения отчётов и сетевой выход не аудитированы. Реальный релизный гейт не запускался; профиль, Docker-доступ и автоматическая загрузка judge.local.env гейтом L13 не проверены. Перенос внутри компании не объявляется завершённым.
